# Premium Physiotherapy Clinic Website

## Goal
Build a polished, mobile-first one-page website for Dr. Keshav Chaudhary Physiotherapy Clinic that preserves every supplied detail and turns calls, WhatsApp messages, directions, and appointment requests into clear actions.

## Experience
- Create a distinctive forest-green, warm-ivory, and champagne visual system with editorial serif headings and clean sans-serif body text.
- Build a high-impact clinic introduction with rating, hours, trust highlights, and smoothly animated statistics.
- Add an interactive pain guide with six tabs, clear treatment details, and pre-filled WhatsApp follow-up.
- Present the clinic approach, six services, four treatment methods, five-step patient journey, team, five Google review stories, six FAQs, and visit details.
- Add an appointment dialog with all requested fields and a dynamically generated WhatsApp message.
- Include direct call, WhatsApp, directions, mobile quick actions, and a back-to-top control.

## Accessibility and quality
- Use semantic sections, one clear page heading, keyboard-operable tabs/dialog/accordion, visible focus states, descriptive labels, and reduced-motion support.
- Keep touch controls comfortable and content readable across phone, tablet, and desktop layouts.
- Add page-specific search and social metadata.

## Technical details
- Implement the page in the existing TanStack Start route and token system.
- Use existing Lucide icons and lightweight CSS/React animations; no database is required because booking hands off to WhatsApp.
- Use Google Maps directions links and an embedded location view without requiring a new service connection.
- Verify the rendered page at desktop and mobile sizes, including tab changes, FAQ expansion, dialog behavior, generated WhatsApp URL, and sticky controls.
